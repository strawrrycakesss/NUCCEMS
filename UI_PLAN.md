# NUCEMS UI Plan

## Landing
Hero section, emergency-report CTA, dashboard CTA, system purpose.

## Dashboard
Stat cards, incident chart, active incident list, responder availability.

## Incidents
Search, filters, table, priority/severity/status badges, actions.

## Report Emergency
Title, description, type, severity, location, reporter. React Hook Form + Zod.

## Incident Details
Incident summary, calculated priority, assignment, timeline, response time.

## Responders
Responder table/cards, availability, skills, workload.

## Locations
Campus location cards/table, risk level, incident count.

## Assignments
Assignment status, timestamps, responder, incident.

## Statistics
Incident counts, type distribution, active/critical totals, response-time analysis.

## Visual system
Primary: navy/deep blue.
Neutral: slate/white.
Critical: red.
Warning: amber.
Success: green.
Use red/amber only for status meaning, not as the whole interface.

## Responsive target
Design for 375px mobile width and desktop. Avoid horizontal overflow. Use stacked cards on mobile and tables with controlled overflow where needed.
